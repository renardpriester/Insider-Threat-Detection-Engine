# AI-Assisted Insider Threat Detection Platform

## Overview

The AI-Assisted Insider Threat Detection Platform is a custom-built cybersecurity monitoring and investigation solution designed to simulate modern Security Operations Center (SOC) workflows for insider threat detection.

This project combines:

* real-time security monitoring
* machine learning anomaly detection
* analyst investigation workflows
* geographic threat visualization
* role-based access control
* persistent case management

The platform was built using Python, Streamlit, SQLite, Pandas, and Plotly.
